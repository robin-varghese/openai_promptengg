This Jupyter Notebook is developed to experiment the lessons taught in ChatGPT Prompt Engineering for Developers (https://learn.deeplearning.ai/courses/chatgpt-prompt-eng/lesson/2/guidelines). Since the course content is built with old version of Python and OpenAI package, its dificult to use the scripts. This Jupyter Notebook is developed using Python version 3.12.2 & OpenAI 1.59.6. Inorder manage different versions of Python I am using Conda in my Macbook. 

For explanation of the code, please refer the notebook itself. 
Generate the API key from https://platform.openai.com/settings/organization/api-keys 
Inorder to save the API Key, add a file in the project directory with name .env and add the API key. Use the reference in the code. 

Also add a file .gitignore in the project directory and add .env file in this. This will restrict local git sending the .env file to the remote repo.
